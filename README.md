# Cyberdeck

Cyberdeck is an unofficial desktop database and deck builder for the Cyberpunk Trading Card Game.

Built with C#, WPF, .NET, EF Core, and SQLite, Cyberdeck allows players to browse cards, search and filter the database, and create and manage deck lists.

## Features

* Card database browser
* Search by card name and text
* Filter cards by color and type
* Card image support
* Deck building and editing
* Save and load decks locally
* Offline SQLite database

## Installation

1. Navigate to the Releases page.
2. Download the latest release zip file.
3. Extract the archive.
4. Run `Cyberdeck.Desktop.exe`.

No additional installation is required.
