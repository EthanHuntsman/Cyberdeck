# Cyberdeck Roadmap

This roadmap represents planned features and goals for future Cyberdeck releases. Features and priorities may change over time.

## Version 1.x Goals

### Database Improvements

* Add newly released cards as they become available.
* Improve card search functionality.
* Add additional filtering options.

### Deck Builder Improvements

* Export deck lists.
* Import deck lists.
* Deck statistics and card breakdowns.
* Improved deck management workflow.
* Core deck building rules/regulations check

### UI Improvements

* Additional card views.
* Improved layout and responsiveness.
* Better card image presentation.

---

## Future Goals

### Collection Tracker

Track owned cards and collection progress.

### Advanced Deck Analysis

* Curve analysis
* Color distribution
* Cost statistics
* Deck legality checks

### Community Features

* Deck sharing
* Import/export codes

### Long-Term Vision

Become a complete Cyberpunk TCG companion application for deck building, card browsing, collection tracking, and analysis.
